# MLCOURSE Environment Setup

This repository contains the setup instructions for the MLCOURSE Python environment, ensuring all team members have a consistent development setup.

---

## Step 1: Install Conda

Download and install [Anaconda](https://www.anaconda.com/products/distribution) or [Miniconda](https://docs.conda.io/en/latest/miniconda.html) if not already installed.

---

## Step 2: Initialize Conda in your shell

Open your terminal (PowerShell, Command Prompt, or Bash) and run:

```bash
conda init
conda create -n MLCOURSE python=3.9
conda activate MLCOURSE
```
